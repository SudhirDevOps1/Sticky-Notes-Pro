📋 JSON Import/Export

🆕 Direct JSON Paste Feature

Click the 📋 JSON button to open the JSON Editor and paste notes directly!

Single Note JSON

{ "title": "Never Outshine the Master", "content": "Apne boss ko kabhi overshadow mat karo", "bullets": ["Point 1", "Point 2", "Point 3"], "type": "law", "preset": "yellow", "effect": "fold", "attach": "tape", "font": "kalam", "fontSize": "base", "rotation": 2 }

Multiple Notes Array

{ "notes": [ { "title": "Law 1", "content": "...", "preset": "yellow", "effect": "fold" }, { "title": "Law 2", "content": "...", "preset": "blue", "effect": "curved" } ] }

Available JSON Fields

FieldTypeOptions
titleStringNote title
contentStringMain content
bulletsArrayBullet points
typeStringlaw, meaning, example, impact, takeaway, quote, tip, warning...
presetStringyellow, pink, blue, green, purple, orange, cyan, rose...
effectStringfold, curved, torn, stacked, notebook, polaroid, neon, glass...
attachStringtape, tape-corner, pin, pin-gold, clip, staple, magnet, none...
fontStringinter, poppins, kalam, caveat, pacifico, hindi...
fontSizeStringxs, sm, base, lg, xl
rotationNumber-8 to 8 degrees

💻 Installation

1 Quick Start - Direct Use

Simply open index.html in any modern browser!

2 Clone Repository

git clone https://github.com/SudhirDevOps1/sticky-notes-pro.git cd sticky-notes-pro

3 Live Server (Optional)

# Using Python python -m http.server 8000 # Using Node.js npx serve . # Using PHP php -S localhost:8000

Then visit http://localhost:8000

📦 CDN Dependencies (Auto-loaded)

<!-- Tailwind CSS --> <script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script> <!-- html2canvas for image export --> <script src="https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js"></script> <!-- Google Fonts (18 fonts) --> <link href="https://fonts.googleapis.com/css2?family=..." rel="stylesheet">

📖 Usage Guide

📝 Method 1: Text Input

Type or paste structured text:

Day 1 – Laws 1 to 3 Law 1: Never Outshine 👑 Meaning: Apne boss ko... Example: Office meeting... Takeaway: - Point 1 - Point 2

🎨 Method 2: Visual Builder

  1. 1. Click ➕ Create button
  2. 2. Style Tab: Choose color, effect
  3. 3. Content Tab: Add title & content
  4. 4. Advanced Tab: Pick font, rotation
  5. 5. Preview Tab: See live preview
  6. 6. Click ✅ Add Note

📋 Method 3: JSON Import

  1. 1. Click 📋 JSON button
  2. 2. Paste your JSON array
  3. 3. Click 📥 Import from JSON
  4. 4. Notes are instantly created!

🎨 Method 4: Quick Presets

Click 🎨 Presets for one-click styled notes:

⚖️ Law Card 💡 Meaning 📌 Example ✨ Impact 🎯 Takeaway
